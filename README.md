## Sobre mim

Sou desenvolvedor de software, fundador e dono da **[TundraLab](https://github.com/TundraLab)**, onde crio aplicações desktop, ferramentas para Linux, projetos web e software sob medida.

Gosto de construir software direto ao ponto, com interface bem cuidada e bom desempenho na prática. Boa parte dos meus projetos públicos fica organizada na organização da **[TundraLab](https://github.com/TundraLab)**.
